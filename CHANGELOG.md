# Changelog

## 1.4.9 (2026-11-05)

Initial public release of DateWithMe by Orictux.

- First-run setup, personalized branding and a 16-language interface.
- Custom invitations, activity decks, preview mode and date scheduling.
- Runaway No button, optional surprises, photo gallery and notifications.
- Responsive admin dashboard and optional Bitcoin support section.
- Docker Compose, native Linux instructions and MIT licensing.
